# Sai Pavan's Portfolio Website

A modern, high-performance portfolio website showcasing data engineering expertise, projects, and insights.

**Live Site:** [saipavan1925.github.io/portfolio](https://saipavan1925.github.io/portfolio)

## 🚀 Features

- **Modern Design** - Tech-industry color scheme with smooth animations
- **Responsive Layout** - Mobile-first design that works on all devices
- **Project Showcase** - 5 major projects with metrics and impact
- **Skills Visualization** - Organized tech stack and certifications
- **Blog Section** - Write and publish articles about data engineering
- **Dark Mode** - Eye-friendly dark theme optimized for code
- **SEO Optimized** - Metadata and structured data for search engines
- **Fast Performance** - Built with Next.js for optimal speed

## 📋 Tech Stack

- **Next.js 14** - React framework for production
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icons
- **Static Export** - Deploys to GitHub Pages

## 🛠️ Setup & Development

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## 🚀 Deploy to GitHub Pages

1. Create repository at https://github.com/new (name: `portfolio`)
2. Connect and push:
   ```bash
   git remote add origin https://github.com/saipavan1925/portfolio.git
   git push -u origin main
   ```
3. Enable GitHub Pages in Settings
4. Visit: `https://saipavan1925.github.io/portfolio`

## 📝 Customize

Edit the following files to personalize:
- `components/Hero.tsx` - Your bio
- `components/Projects.tsx` - Your projects
- `components/Skills.tsx` - Tech stack
- `components/Experience.tsx` - Work history
- `app/blog/` - Add blog posts
